\section{Reproducibility and release}
\label{app:repro}
\paragraph{Code.} \url{\codeurl} contains the model, training and sampling code, the
evaluation and fitting code, the run records and per-item scores of the released runs, the
pre-registration documents, and scripts that rerun each stage. \texttt{REPRODUCE.md} names
the script and the input files behind every table and figure. The code is released under the
MIT licence and the model weights under CC BY-NC 4.0.

\paragraph{Models.} The model repository holds the checkpoints of all \NcrrGridRuns\ grid
runs and of the \NcrrSweepRuns\ learning-rate sweep runs, each with its configuration and
training record. It also holds extension checkpoints at the \NmaxNfour\,M budget and at 90k
training steps, and the measured surface with its fits: \url{\modelurl}. It also holds audio
samples at $T{=}1$ and $T{=}16$ with their prompts and real targets.

\paragraph{Compute.} Training the \NcrrGridRuns\ grid runs took \NcrrGridTrainGpuh\
GPU-hours on \NcrrDevice\ GPUs. With the learning-rate sweep (\NcrrSweepGpuh) and the
synthesis for the grid (\NcrrGridSynthGpuh), the main study used \NcrrMainGpuh\ GPU-hours.
The extension runs with released records add \NcrrExtTrainGpuh\ GPU-hours of training.
Later runs without GPU-hour records in the repository are not counted: most of the
180k-step runs, the classifier-free guidance check and the F5-TTS anchor. All GPU-hour values
are sums of each job's wall-clock time. Small jobs often shared one GPU, so the sums overstate
exclusive GPU time.

\paragraph{Where the numbers come from.} Measured values in the text, tables and figures are
LaTeX macros that scripts in \texttt{src/} write from committed artifacts. On a CPU,
\texttt{recipes/reproduce\_paper\_cpu.sh} regenerates the macro files from the released
records and compares them with the copies used here. The run records behind the 180k-step row of Table~\ref{tab:trend} are not yet part of the
public release, so the recipe reports those values as unverifiable.
Design constants, such as step counts, $T$, $K$, widths and depths, are typed.
