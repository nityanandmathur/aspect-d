# docs

The project website. GitHub Pages serves this folder (branch `main`, path `/docs`) at
<https://nityanandmathur.com/aspect-d/>. Everything in it is public. `.nojekyll` makes Pages
serve the files as they are, without a Jekyll build.

The paper's numbers are not taken from these pages. They are generated by scripts in
`src/` from the committed results (see [../REPRODUCE.md](../REPRODUCE.md)).

| Path | Contents |
|---|---|
| `index.html` | Project page |
| `motivation.html` | Theory and motivation page written before the experiments |
| `protocol.html` | Experimental protocol: thresholds, gates G0 to G6, deliverables |
| `implementation.html` | Implementation notes and the environment as executed |
| `results.html` | Results of the main grid (first generated by `src/report.py`, since annotated by hand; regenerating it in place drops the annotations) |
| `extensions.html` | The v1.1 extension studies |
| `coordinate-audit.html` | The v1.4 coordinate audit (generated by `src/make_audit_page.py`) |
| `samples/` | Listening page and audio for four evaluation items (generated by `src/samples.py`) |
| `assets/` | Figures and files used by the pages |
| [preregistration/](preregistration/) | The v1.0 pre-registration and its four addenda (v1.1, v1.2, v1.3, v1.5), with the commit that froze each one |
