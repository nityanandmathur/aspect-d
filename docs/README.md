# docs

Process documents from the research. You do not need them to run the code or the models.
They are not a source of numbers either: the paper's numbers are generated by scripts in
`src/` from the committed artifacts (see [../REPRODUCE.md](../REPRODUCE.md)).

| Folder | Contents |
|---|---|
| [preregistration/](preregistration/) | The four pre-registration addenda (v1.1, v1.2, v1.3, v1.5), with the commit that froze each one. The v1.0 pre-registration is [../PREREGISTRATION.md](../PREREGISTRATION.md) at the repository root. |
| [research-log/](research-log/) | Runbooks, decision logs and execution state that were moved out of the repository root, plus [README-research.md](research-log/README-research.md), the research-phase README with its errata, status and canonicality notes |

Several other process files stay at the repository root because scripts read or write them
there: `LOG.md`, `LOG-v1.1.md`, `DECISION.md`, `RESULTS-FEED.md`, `state.json`,
`state-v1.json`, the `*.html` project pages, `logs-v1.5/` and `.claims-v1.5/`.
[research-log/README.md](research-log/README.md) explains why.
